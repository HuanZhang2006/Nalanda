# 治理文档索引

> **本文内容：**汇总 Nalanda 对个人数据、内容、审核、事件与长期运营责任的治理规范。  
> **作用：**为产品、工程、客服、安全和运营提供统一入口，并把政策目标与当前技术能力分开。  
> **何时更新：**新增治理领域、政策所有者/流程变化、目标市场或法规变化，或索引中文档改名时。  
> **状态基线：**2026-07-10；治理要求不等于当前已经有对应后台或自动化。

| 文档 | 负责问题 | 当前实现摘要 |
|---|---|---|
| [隐私与数据删除](PRIVACY_AND_DATA_DELETION.md) | 数据分类、访问/导出/删除、留存、备份与第三方处理 | 部分依靠 Supabase RLS；无完整 DSAR/删除编排 |
| [内容审核](CONTENT_MODERATION.md) | 禁止内容、举报、处置、申诉、版权和透明度 | 社区 CRUD 已有；无举报/审核后台和状态机 |

治理文件定义产品和运营必须达到的行为；实际能力以代码、迁移和可执行测试为证据。新增规则时，应同时指定负责人、数据模型/API、观测指标、用户通知、申诉/纠错和上线门禁。
