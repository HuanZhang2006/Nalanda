# ADR-NNNN：决策标题

> **本文内容：**记录一个重要、长期或难以逆转的技术/产品架构决策。  
> **作用：**保存决策背景、备选方案、取舍、后果和落地证据，供实现与复盘使用。  
> **何时更新：**评审状态变化、实现状态变化、出现关键新证据或被新 ADR 替代时；Accepted 后不得改写原结论。  
> **模板说明：**创建 ADR 时删除本行，并替换所有占位内容。

- **状态：**Proposed

- **决策者：**角色或团队
- **范围：**受影响系统
- **关联：**Issue/PR/文档/后续 ADR
