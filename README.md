# Nalanda

> 以古印度那烂陀大学命名——世界上最早的知识殿堂。

**Nalanda** 是一款多平台 AI 学习辅助工具，专为大学生设计。一键将 PPT、Word、PDF 课件转化为结构化学习资产，从预习到期末一站式覆盖。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| **知识清单** | 自动提取课件核心概念，生成结构化知识点列表 |
| **交互式测试题** | 根据课件内容生成选择、填空、简答等多种题型，即时反馈 |
| **知识图谱** | 可视化概念关联，帮助建立知识体系，理清脉络 |
| **仿真期末试卷** | 按课程难度分布生成仿真试卷，模拟真实考试场景 |

## 使用场景

- **课前预习**：上传课件，快速掌握本节重点，带着问题去听课
- **课后复习**：知识清单 + 测试题，检验理解程度，查漏补缺
- **备考冲刺**：仿真试卷模拟期末，知识图谱串联整个学期内容

## 支持格式

- **PPT / PPTX** — 课堂讲义、教学幻灯片
- **Word / DOCX** — 讲义、学习指导
- **PDF** — 教材章节、扫描讲义

## 平台支持

- Web（浏览器）
- iOS / Android（移动端）
- macOS / Windows（桌面端）
